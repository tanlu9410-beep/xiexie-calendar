# 蟹蟹桌宠 · Mac 原型

原项目的动画由 Claude 绘制，小船审稿与验收；本分支为 Li-0803 fork 的非商用桌宠改编。原日历、图鉴和美术文件保持不变。

## 使用

解压 `build/蟹蟹桌宠.zip`，将其中的「蟹蟹桌宠.app」放进本机「应用程序」文件夹后双击。螃蟹默认出现在主屏幕右下角；菜单栏会出现 🦀。构建脚本还会打印临时目录内可直接测试的 App 路径。

- 单击：下一个职业。
- 按住左键拖动：移动窗口。
- 右键或菜单栏 🦀：指定职业、暂停动画、调整大小、找回窗口、查看署名或退出。
- 记住位置、大小和职业；不开机自启，不接 AI，不读取其他应用数据，不发起网络请求。

当前池子包含 37 个造型变体（包括同职业不同动作及特别造型）；未新增或修改原项目的像素美术。

透明矩形窗口目前仍会占用它覆盖区域的鼠标事件，不是按像素穿透；暂不支持自主行走、碰撞、日程和提醒。

## 构建与测试

需要 macOS 12+、Apple Command Line Tools（提供 Swift）以及用于自动测试的 Node.js；不需要 Electron、Python 或第三方运行时。

```sh
node --test desktop/test.mjs
bash desktop/build.sh
```

生成的是当前 Mac 架构的本地开发版（Apple Silicon 或 Intel，不是双架构通用包），编译目标为 macOS 12.0。实际运行验证目前仅在开发者的 Apple Silicon Mac 上进行，尚未实测 Intel 或旧版 macOS。

构建脚本只对生成的应用使用本地 ad-hoc 签名，并未取得 Apple Developer ID 签名或公证；不能把本机可运行等同于其他 Mac 可直接安装。若系统拦截第三方分发版本，请先核对来源，不要为此关闭 Gatekeeper 或 SIP。

构建缓存及 ZIP 不纳入 Git；脚本会将应用构建到临时目录，避免 iCloud 自动添加 Finder 元数据干扰签名，然后在 `build/` 中生成 ZIP。需要长期使用时，请将应用放进「应用程序」，不要依赖临时目录长期保留。

## 验证范围

- 自动化：遍历全部造型，检查 SVG 与四帧结构；切换循环、无效保存值回退、暂停状态、离线策略；Swift 编译和生成应用的签名校验。
- 已观察：透明悬浮显示、点击更换职业、右键菜单；用户已在桌面看到并试用原型。
- 待进一步验证：拖动与点击的边界、跨显示器恢复位置、睡眠唤醒和长时间资源占用；不把这些列为已通过的测试。
- GitHub Actions 配置会在 macOS runner 上执行渲染测试和构建；本地完成提交不代表远程 CI 已运行。
